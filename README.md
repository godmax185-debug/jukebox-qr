# JUKEBOX QR — เวอร์ชันเพิ่มคิวเพลงและมาสคอต

ต่อยอดจากโปรเจกต์เดิม โดยคง React + Vite, YouTube Data API, YouTube IFrame Player, QR Code และ Supabase ไว้

## เพิ่ม/ปรับปรุงในเวอร์ชันนี้
- แสดงเพลงที่กำลังเล่นเป็นลำดับ 01 และเพลงรอเล่นเป็น 02, 03, ... ทั้งหน้าจอหลักและหน้าขอเพลง
- เพลงที่ขอใหม่จะเพิ่มท้ายคิว ไม่เปลี่ยนเพลงที่กำลังเล่น
- เพิ่มมาสคอตเสืออ้วนกับฮิปโปอ้วนสไตล์ CGI 3D และเอฟเฟกต์โยก/เด้งด้วย CSS
- ปุ่มเปิด–ปิดเอฟเฟกต์เต้น จำค่าที่เลือกไว้ในเบราว์เซอร์
- ปรับการโหลดสถานะปัจจุบันให้ล้างข้อมูลเพลงเก่าเมื่อไม่มีเพลงกำลังเล่น

## โครงสร้าง
- `src/App.jsx` — หน้าจอหลัก, คิวเพลง, YouTube player, QR และตัวควบคุม
- `src/main.jsx` — จุดเริ่มต้น React
- `src/style.css` — รูปแบบและแอนิเมชัน
- `public/assets/tiger-hippo-duo.png` — ภาพมาสคอต
- `supabase-schema.sql` — SQL schema/functions ที่ใช้กับโปรเจกต์เดิม
- `.env.example` — ตัวอย่างตัวแปรสภาพแวดล้อม

## ติดตั้ง
1. ใช้ Node.js 20 ขึ้นไป
2. แตก ZIP แล้วเปิดโฟลเดอร์โปรเจกต์
3. คัดลอก `.env.example` เป็น `.env` และกรอกค่าของโปรเจกต์คุณ:
   - `VITE_SUPABASE_URL`
   - `VITE_SUPABASE_ANON_KEY` (ใช้ publishable/anon key เท่านั้น ห้ามใส่ service_role/secret key)
   - `VITE_YOUTUBE_API_KEY`
   - `VITE_ADMIN_PIN`
   - `VITE_ROOM_URL`
4. ติดตั้งและรัน:
   ```bash
   npm install
   npm run dev
   ```
5. หน้าจอหลักใช้ URL ปกติ ส่วนหน้าสำหรับขอเพลงใช้ `/?request=1`

## Supabase
หากรัน SQL ของโปรเจกต์เดิมเรียบร้อยแล้ว ไม่ต้องรัน `supabase-schema.sql` ซ้ำ ใช้ฐานข้อมูลเดิมได้เลย

## ข้อควรทราบก่อนเปิดใช้งานจริง
- Starter เดิมใช้ `VITE_ADMIN_PIN` ฝั่ง client เพื่อแสดงการควบคุม และตรวจ PIN ซ้ำใน RPC; การฝัง PIN ใน frontend ไม่ถือว่าปลอดภัยสำหรับ production ควรย้ายการยืนยันเจ้าของไป Edge Function/ระบบ auth ฝั่ง server
- ควรเพิ่ม rate limit, moderation และการป้องกันสแปมก่อนเปิดให้คนทั่วไปใช้
- YouTube autoplay อาจถูกเบราว์เซอร์บล็อกจนกว่าจะมีการกดเล่นครั้งแรก และบางวิดีโอไม่อนุญาตให้ฝัง
- ภาพมาสคอตเป็นภาพนิ่งที่ทำให้เคลื่อนไหวด้วย CSS (โยก/เด้ง) ไม่ได้วิเคราะห์จังหวะเสียงจริง
